# Exemptions for check-no-committed-secrets.mjs.
#
# Format:  <repo-relative path> :: <the exact matched text>
#
# Intentionally EMPTY. Nothing in the tree needs exempting today.
#
# The literal is required, and that is the safety property: an entry can only
# exempt a value you are willing to write down here in plaintext. For the token
# patterns the match IS the secret, so a real credential cannot be allowlisted
# without leaking it -- the only route past the gate is rotate and remove.
#
# The private-key check is marked `allowlistable: false` in the script, because
# its match is a fixed PEM header carrying no key material: one entry would
# otherwise exempt every key in that file. It cannot be allowlisted at all. If
# a private key is reported, the answer is to remove it, never to list it here.
#
# A literal may use \n to express a match that spans lines.
#
# This file is scanned like any other. Only the literal half of a well-formed,
# non-comment entry is exempt, so a credential pasted into a comment here is
# caught. Entries matching nothing, and lines missing the separator, are
# reported on every run.
