# Exemptions for check-no-committed-secrets.mjs.
#
# Format:  <repo-relative path> :: <the exact matched text>
#
# Intentionally EMPTY. Every pattern in the gate matches the high-entropy
# secret itself, so a legitimate file should never match, and nothing here
# needs exempting today.
#
# The literal is required, not optional, and that is the safety property: an
# entry can only exempt a value you are willing to write down here in plaintext.
# A real credential therefore cannot be allowlisted -- writing it here would
# leak it -- so the only route past the gate for a real secret is rotate and
# remove.
#
# The property depends on every pattern's match containing the secret. A
# pattern matching a fixed zero-entropy marker (a bare PEM header, say) would
# let one entry exempt every real secret carrying that marker. An earlier
# revision of this gate had exactly that hole.
#
# This file is itself scanned. Only the literal half of a well-formed entry is
# exempt, so a credential pasted into a comment here is caught like anywhere
# else. Entries matching nothing are reported on every run.
