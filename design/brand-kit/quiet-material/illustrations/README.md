# Shared-access illustration

This candidate companion explains one relationship: an agent connects to Strale, then uses that shared access path for research, extraction or validation. It is a conceptual diagram, not a captured request or a claim that one call runs all three tasks.

Edit geometry and rendering values in `../../../tokens/candidates/quiet-material-illustrations.json`, then run:

```powershell
node build.mjs
node verify.mjs <playwright/index.mjs>
node build.mjs --check
```

`masters/` contains the editable light desktop and narrow SVGs. `exports/` contains fixed light and inverse variants plus the two review screenshots. Every SVG embeds the bundled Instrument Sans font as a data URI and retains the exact existing Strale lockup paths.

The diagram geometry is original to this candidate. The retained logo's creation and rights history remains pending, as recorded in the foundation registry. These files make no new logo-rights, publication, or production-adoption claim.
