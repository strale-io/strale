## Decision

The quotation convention for this candidate set is unchanged from
`DEC-20260905-J`: normalize quotation and source before comparing:
transliterate `€` to `EUR`, `×` to `x`, `≥` to `>=`, `≤` to `<=`, `→` to
`->`, `…` to `...`; lowercase; delete every character that is not a
letter or digit. A quotation is faithful when its normalized form is a
substring of the normalized source (an ellipsis splits it into ordered
segments). Punctuation, dashes, quote marks, case, markdown emphasis,
whitespace and the punctuation at a truncation point are therefore never
defects. Defects are: a word inserted, dropped, replaced or reordered; a
composite presented as one quotation; a quotation whose named source does
not contain it (wrong file, function, document, record or row field); a
quotation attributed to a source outside the repository, the parsed row,
the sibling frontend checkout or a merged pull request; and any false
statement about repository state at the commit.

The statements listed below are withdrawn from the named records and
replaced by the facts stated here.

### `DEC-20260905-C`

1. Withdraws, as the record has it (lines 142-144): "CLAUDE.md does state
   the platform is "Vertical-agnostic" and describes a long-term
   ambition to scale broadly, but not in this wording." Fact: at commit
   `0fd6364f` `CLAUDE.md` contains neither the word "vertical-agnostic"
   in any case (confirmed by `git grep -n -i "vertical-agnostic" 0fd6364f
   -- CLAUDE.md`, zero matches) nor any statement of a long-term ambition
   about the number of data sources; a full-file read at this commit
   turns up neither. The word "Vertical-agnostic" exists only in the
   user's own external `MEMORY.md` file, which `DEC-20260905-C`'s own
   item already rules out as a source for exactly this claim ("which is
   not part of the repository this candidate set is drawn from"). So
   `CLAUDE.md` at this commit does not describe the platform as
   vertical-agnostic and states no long-term data-source ambition; the
   original record's characterization ("vertical-agnostic ('Long-term
   ambition is tens/hundreds of thousands of data sources,' per project
   memory)") has no repository source, and `DEC-20260905-C`'s withdrawal
   of that quoted phrase stands undisturbed by this correction. Evidence:
   `CLAUDE.md`; `docs/decisions/records/DEC-20260905-C.md` (lines
   134-144); `docs/decisions/records/DEC-20260224-P-g7h8.md` (lines
   70-75).

## Rationale

A correction is checked like any other claim, and one that asserts a
source the repository does not contain is withdrawn like any other
false statement; an inserted word inside brackets is still an inserted
word under the convention.
