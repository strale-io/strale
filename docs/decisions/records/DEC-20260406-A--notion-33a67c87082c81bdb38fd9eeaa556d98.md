## Decision

Consolidate the rules governing Claude (chat), Claude Code, and Notion
governance into a single source-of-truth page.

## Context

The row's stated basis, from its own Rationale: rules governing
Claude/CC/Notion behaviour were previously fragmented across memory
entries, session logs, and individual CC prompts, producing rule drift
and unclear authority when memory and session context disagreed.
Consolidation into a single governed page establishes a hierarchy: the
Working Rules page is canonical, DEC entries record rule changes, and
memory holds pointers rather than rule text. Four rules were
consolidated: (A) a strategy carve-out allowing Claude to flag
foundational questions and switch to alternatives-with-trade-offs mode,
(B) the Distribution Registry governance pattern applied to all
strategic docs with a mandatory governance header, (C) a formalised
five-point audit-phase checklist for CC prompts including
upstream/downstream implications, (D) a clarified build-first-then-talk
rule distinguishing product claims from problem-framing content. The row
states this consolidation is the foundation for the Notion cleanup
session and unblocks the Tier 1 strategic sessions that follow.

This historical ID is reused by a second, unrelated Notion row (a fix
for missing per-step `latencyMs` capture in the solution audit trail,
made the same day) and was an unresolved registry collision until this
batch; the two rows are resolved together in
`archive/sessions/2026-09-05-decision-collision-resolution-DEC-20260406-A.md`
with distinct source-qualified record keys. This record covers only the
working-rules-consolidation row.

The historical Notion scope field on this row was `global`. It is
recorded here as `scope: product`: it is a governance and
process-organization decision, not a technical implementation.

## Rationale

The rationale, as the row states it: fragmented rule locations produce
drift and unclear authority; a single governed page with DEC entries as
the change log and memory as pointers removes the ambiguity, at the cost
of requiring the consolidation work itself.

## Consequences

Status verified on 2026-09-05, against `main`.

**The single-source-of-truth model this row built in Notion has since
been substantially superseded by a repo-native operating model, not
merely extended.** CLAUDE.md's own "Workflow Protocol" section (the
opening section of this repository's CLAUDE.md) documents review
routing, a program register, research and idea locations, design
tokens, evidence receipts, and a "Session contract" naming
`docs/programs/README.md` as where multi-batch work resumes — none of
which existed as this row's "single governed page" model. `docs/company/CHARTER.md`
states it "AMENDS DEC-20260812-A's escalation contract" and is described
there as canonical operating authority ("if they ever diverge, this file
is the text and the other two are pointers to it"), a role structurally
similar to this row's "Working Rules page is the canonical source"
principle but implemented as a repo file rather than a Notion page.
`docs/programs/README.md` states program registers are "execution
records, not project truth," with project truth living in
`docs/project/` and `docs/decisions/`.

**CLAUDE.md still documents a Notion-side governance structure
alongside the repo-native one**, not a full migration away from Notion:
its "Notion Governance Rules (enforced)" section still states "Check
before creating," "ONE page per topic," and other rules matching this
row's stated consolidation intent, run in parallel with the repo-native
model rather than as its replacement. This record does not resolve
whether CLAUDE.md's Notion-governance section is the row's original
consolidated page carried forward as prose, or an independent
restatement; both surfaces exist on `main` today.

## Reversal conditions

None recorded on the row (`Superseded By` is null in the source). The
Consequences above record that a broader repo-native operating model has
since developed alongside this row's Notion-page consolidation; a future
decision formally reconciling the two would be the natural successor
record, not yet present.
