## Decision

The quotation convention for this candidate set is unchanged from
`DEC-20260905-I`: normalize quotation and source before comparing:
transliterate `€` to `EUR`, `×` to `x`, `≥` to `>=`, `≤` to `<=`, `→` to
`->`, `…` to `...`; lowercase; delete every character that is not a
letter or digit. A quotation is faithful when its normalized form is a
substring of the normalized source (an ellipsis splits it into ordered
segments). Punctuation, dashes, quote marks, case, markdown emphasis,
whitespace and the punctuation at a truncation point are therefore never
defects. Defects are: a word inserted, dropped, replaced or reordered; a
composite presented as one quotation; a quotation whose named source does
not contain it (wrong file, function, document, record or row field); a
quotation attributed to a source outside the repository, the parsed row,
the sibling frontend checkout or a merged pull request; and any false
statement about repository state at the commit. The relation rule is
also unchanged: a relation declared in a record's frontmatter whose basis
is stated in an amending record, or narrated in the target record's own
body, is substantiated; the narration need not live in the source
record's own body once that basis is stated somewhere reachable from the
record. `DEC-20260905-I`'s dated-observation clause (a figure a record
states as of a date is not a defect merely because unrelated work later
moves it, and an amending record's affirmation of it that was true at
that record's own commit is not a wrong correction) also carries forward
unchanged. This record adds one further clause: a quotation of a
published statute or regulation that the sentence names by instrument and
article (for example GDPR Article 30) is verifiable against that public
instrument and is not an unverifiable source; it is checked against the
statute's own text, which lives outside this repository by design, and is
Not adopted under this clause rather than withdrawn as unverifiable.

The statements listed below are withdrawn from the named records and
replaced by the facts stated here, grouped by record in filename order.
Two further items, against `DEC-20260430-A`, substantiate without
withdrawing anything a relation this round's own review re-confirmed
holds, restating the basis `DEC-20260905-F`, `-H`, and `-I` already state
so this record carries it too, in the form `DEC-20260905-E` item 6 used.

## Rationale

One amending record per remediation round keeps history immutable, keeps
the reviewer trail intact, keeps the validator's protections untouched,
and matches a stable evidence file
(`archive/sessions/2026-09-05-m2-closing-review-round-9.md`). The
quotation convention, restated unchanged from `DEC-20260905-I`, continues
to remove reviewer disagreement about what counts as a defect; the one
clause this record adds (a statute cited by article is a verifiable
public source, not an unverifiable one) does not weaken the bar on words,
attribution, or facts, it only recognizes that a law's own text is a
real, checkable source that happens to live outside this repository, the
same way a merged pull request or the sibling frontend checkout already
counts as a real source under the existing convention.

The quotation class is closed by checking every double-quoted span
against its own named source once, corpus-wide, rather than by sampling a
handful per round and hoping the pattern that catches most defects also
catches the last few. Nine rounds each found a few misquotations by
direct reading; the sweep this round ran shows why sampling alone never
converges: the operator checker's own substring search is blind to
*which* source a sentence names, so a defect can hide behind any
coincidentally-matching text anywhere else in the corpus indefinitely.
Checking every span against its own named source, once, for the whole
corpus, is the only way to know the quotation class has actually been
exhausted rather than merely sampled again.
