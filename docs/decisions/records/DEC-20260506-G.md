## Decision

For v1 implementation sequencing in business-register vendor selection,
default to paths with zero or near-zero fixed costs. Defer commitments to
monthly subscriptions, package floors, and minimum-spend tiers until
customer traffic justifies them.

## Context

Strale is recorded as pre-revenue at the time of this row; fixed monthly
commitments compound burn against zero customer signal. The row names two
prior findings as establishing the pattern this row formalizes as default
policy: a pricing benchmark study (`DEC-20260422-H`, no formal record
exists for that id on `main` and it is not in
`docs/decisions/id-collisions.yaml`, mentioned in prose only) and
`DEC-20260506-F` (classifying the Austrian Verrechnungsstelle as
v1-incompatible; no formal record exists for that id either, mentioned in
prose only); both are recorded as having established that fixed-cost-heavy
paths invert v1 unit economics.

The row records an explicit trade-off: where Free, pay-as-you-go, or
public-source paths are unavailable, business-register coverage will lag.
This is stated as preferred to pre-committing fixed monthly spend at zero
customer signal.

The historical Notion scope field on this row was `global` in the
workspace's old vocabulary. It is recorded here as `scope: product` under
this repository's decision-record vocabulary: this sets a default policy
for how the product's data-source portfolio is built, not a single
technical integration choice.

## Rationale

The rationale is burn discipline at zero revenue: a fixed monthly
commitment is a cost regardless of whether it is used, and at zero
customer signal there is no way to size the commitment against demand, so
the row defaults to variable-cost paths and accepts thinner country
coverage as the trade-off.

## Consequences

Status verified on 2026-09-04, against `main`.

**This row predates, and is narrower than, the operating charter's spend
envelope.** `docs/company/CHARTER.md` states an "External spend: EUR
50/week" envelope (line 399) inside which Claude decides day-to-day

operative spend-authority boundary, though it does not contradict this
row's underlying preference for variable-cost paths at low traffic.

does not name any of this row's specific vendor candidates (OpenRegister,
Implisense, Kyckr, Cobalt) by line item, so this record cannot state
whether any fixed-cost vendor commitment this row would have deferred is
now inside the tracked budget.

**Several later rows this batch also migrates cite this row directly**,

(Kyckr rejected in part because its "sales-gated pricing... collides with
DEC-20260506-G no-fixed-cost stance"), `DEC-20260507-E` (OpenRegister's

and Hungary's paid-only paths recorded as conflicting with this row).
