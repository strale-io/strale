## Decision

Add "Trust" to the top-level navbar, distinct from and alongside "Docs."

## Context

The row's stated basis, from its own Rationale: trust and quality are
Strale's core differentiator, so a top-level nav item signals "this is
what we're about" instead of burying trust content inside Docs. Docs
covers API usage; Trust covers methodology.

The historical Notion scope field on this row was `global`. It is
recorded here as `scope: product`: it specifies a single navigation-menu
addition, a UI-surface decision, not a company-wide strategic or purely
technical one.

## Rationale

The rationale, as the row states it: nav placement communicates
priority; putting trust/methodology content at the top level rather than
nested under Docs signals that trust is core to the product, not an
implementation detail.

## Consequences

Status verified on 2026-09-05, against the sibling `strale-frontend`
checkout, read-only.

**A "Trust" top-level nav item exists today.**
`strale-io/strale-frontend@04c9fca9:src/components/Header.tsx` line 10 defines
`{ label: "Trust", href: "/trust" }` in its nav-item list.
