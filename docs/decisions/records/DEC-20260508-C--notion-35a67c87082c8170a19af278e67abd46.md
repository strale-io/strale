## Decision

Claude Code verifies worktree HEAD state at session start. Adds a Worktree
branch-collision tripwire to `stop-conditions.md`.

## Context

Relation to `DEC-20260508-B--notion-35a67c87082c814bbb8df7036fccf8e1`: the
row's Rationale names its predecessor directly: "With DEC-20260508-B locking detached HEAD as the canonical resting state of strale-work and strale-research, the tripwire becomes mechanical." That row establishes the
detached-HEAD worktree structure this tripwire depends on.

The row's Rationale states: "Closes the structural-enforcement gap from the 2026-05-07 Kyckr course-correction. ... With DEC-20260508-B locking detached HEAD as the canonical resting state of strale-work and strale-research, the tripwire becomes mechanical: any unexpected branch in a work worktree at session start signals concurrent CC activity and halts the prompt. Without this rule, only operator vigilance prevents recurrence — the same vigilance that didn't prevent the 2026-05-07 incident."

## Rationale

The rule converts a vigilance-dependent safeguard into a mechanical
tripwire: a detached-HEAD baseline (established by `DEC-20260508-B`) makes
an unexpected branch a reliable, checkable signal rather than a
judgment call.

## Consequences

This repository does not carry a file literally named `stop-conditions.md`
at HEAD, so this record cannot verify the tripwire's continued presence at
that exact path. `CLAUDE.md`'s Shared-Checkout Rule item 3 carries a
related but not identical check: its Shared-Checkout Rule item 3 says to
"check `git status`" before branch-switching in the main tree, for another
session's uncommitted work. This is a
narrower git-status check, not the worktree-HEAD-state tripwire this row
describes; whether the specific rule this row created still runs today is
not verifiable from files in this repository.

## Reversal conditions

Supersede this decision if the worktree-HEAD-state check is replaced by a
different concurrency-safety mechanism, or if `DEC-20260508-B`'s
detached-HEAD baseline itself changes and this tripwire's premise no longer
holds.
