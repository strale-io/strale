## Consequences

Status verified on 2026-09-05, against `main`.

**The Cloudflare Pages hosting choice this row states was itself
subsequently superseded, not merely continued, by a later, active,
codified decision.** `CLAUDE.md`'s Current Decisions (September 2026)
section states, under `DEC-20260902-A`: "The website redesign is built
inside this repository as `apps/web` (monorepo). Directed by Petter
2026-09-02. Preserve first, then build: `strale-frontend` was swept and its
design material preserved... and is kept, not extended, until the `apps/web`
site serves production." That is the opposite structural choice from what
this row states ("sibling-repo structure retained (monorepo deferred)"):
the monorepo this row explicitly deferred is now the adopted direction,
`strale-frontend` is in maintenance rather than active development, and
`apps/web` does not yet exist in this repository as of this record's
verification (`test -d apps/web` finds no such directory; `ls apps/`
lists only `api`).

**The Cloudflare Pages hosting fact itself is corroborated by the sibling
frontend repository's own files.** `strale-frontend` at commit
`04c9fca970d82b2c98145973816d52086b3b91d7` carries `public/_headers`
(a Cloudflare Pages-specific configuration convention, setting
`Strict-Transport-Security` and other response headers) and no
`wrangler.toml`. This is consistent with, but does not by itself prove,
continued production hosting on Cloudflare Pages; this record did not query
the live DNS or hosting provider.
