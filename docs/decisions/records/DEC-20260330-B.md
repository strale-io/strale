## Decision

Shift distribution strategy from "be listed" to "be embedded in coding
workflow" via Context7, IDE rules, and vibe-coding-framed SEO.

## Context

The historical Notion scope field on this row was `global`. It is recorded
here as `scope: product` under this repository's decision-record
vocabulary: this decision governs where and how Strale is discovered by
developers, a distribution-strategy concern.

## Rationale

The "be listed" playbook is exhausted (60+ surfaces, 17 open PRs). Context7
is the #1 MCP server (47K stars, 2x the views of #2) and injects library
docs into coding prompts automatically. Vibe coding has created massive
demand for trust-sensitive data handling (92% dev adoption, 53% of AI code
has vulnerabilities, IBAN/PII exposure in 5,600+ apps). Strale's free-tier
endpoints are a natural safe default. Getting indexed in Context7 means
Strale docs get injected when developers ask about IBANs, sanctions, or
KYB.

## Consequences

Status verified on 2026-09-04, against `main`.

**Both artefacts this row named exist and are live in the repository.**
`context7.json` (root-required by the Context7 crawler; verified present)
lists `folders` including `docs`, `packages/mcp-server`,
`packages/sdk-typescript`, `packages/sdk-python`, and the framework
packages, and carries a `rules` array of 12 developer-facing guidance
strings covering the free-tier capabilities (`email-validate`,
`iban-validate`, `dns-lookup`, `url-to-markdown`, `json-repair`), example
request bodies, SDK package names, and the MCP server URL — directly the
"injected when developers ask about IBANs" mechanism this row describes.
`docs/ide-rules/` carries two IDE-rules artefacts: `strale-compliance.mdc`
and `strale-compliance.windsurfrules`, both covering trust-sensitive data
handling (IBAN and financial-identifier validation, server-side-only
guidance, free validation examples) — the "IDE rules" leg of this row's
strategy.

**One of `context7.json`'s 12 rules cites a deleted endpoint.** Rule 12
reads: "Every capability has a Strale Quality Score (SQS) from 0-100. Check
via `GET /v1/quality/:slug`." Per CLAUDE.md ("SQS scoring engine deleted
per DEC-20260503-B"), the public `/v1/quality/:slug` endpoint no longer
exists; this rule is stale public copy that predates the 2026-05-05 SQS
deletion and was not swept when the endpoint was removed. This is a live
finding, not something this record corrects — `context7.json` is one of the
four root manifests CLAUDE.md's "Root contains exactly" paragraph names as
required-in-place by its registry's crawler, and editing it is outside this
batch's scope.

**Whether the "be embedded in workflow" shift moved the needle on
distribution (activation, traffic attributable to Context7 or IDE-rules
usage) is not recorded in any repository document found for this record;**
this record states only that the artefacts this row committed to exist and
are live, not that their effect was measured.

## Reversal conditions

Reconsider this decision if Context7 or the IDE-rules ecosystem stops
being a material developer-discovery surface, or if the stale
`GET /v1/quality/:slug` rule in `context7.json` is left uncorrected long
enough to actively mislead developers — that drift should be treated as a
live risk to this distribution channel's accuracy, not evidence this
decision is inactive. Represent a change of this decision through a new
decision rather than editing this protected record in place.
