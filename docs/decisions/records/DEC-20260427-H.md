## Decision

Enforce `DEC-20260420-H` (Counterparty Assurance v1's ban on ToS-prohibited
scraping) by deactivating five capabilities found probing sites whose terms
of service forbid automated access: `patent-search` (patents.google.com),
`trustpilot-score` (trustpilot.com), `salary-benchmark` (glassdoor.com),
`employer-review-summary` (glassdoor.com + google.com fallback), and
`linkedin-url-validate` (linkedin.com). A sixth capability,
`social-profile-check`, was trimmed rather than deactivated, to 7
ToS-tolerant platforms out of 11. Manifests and the database were synced.
Each deactivation entry carries a reactivation trigger.

## Context

The row's own Rationale states: "DEC-20260420-H established that
capabilities sourcing data via ToS-prohibited scraping are banned. A

active caps probing sites whose ToS forbids automated access: patent-search
(patents.google.com), trustpilot-score (trustpilot.com), salary-benchmark

72ae170 on main." No record for `DEC-20260420-H` exists in this repository,
so this row's own "Enforce DEC-20260420-H" cannot be recorded as an
`affirms` relation edge per this batch's rule that a relation target must
exist as a record on the PR head; it is noted here in prose only.

## Rationale

The row's logic follows directly from the ban `DEC-20260420-H` established:
a platform-wide audit found capabilities not yet brought into compliance with
that ban, and this decision closes that gap, with per-capability reactivation
triggers rather than a blanket "wait and see."

## Consequences

unreversed.** `apps/api/src/capabilities/auto-register.ts`'s `DEACTIVATED`
map still carries all five slugs, each with a comment citing this decision's
own per-capability suffix: `patent-search` ("DEC-20260427-H-1: Runtime
fetched patents.google.com via Browserless + Claude extraction... Reactivation

## Reversal conditions

Each of the five capabilities carries its own per-capability reactivation
trigger, quoted above from `auto-register.ts`; none has fired as of
2026-09-05. Reversal is per-capability (a licensed API or vendor contract for
that specific data type), not a single blanket condition for this row.
