## Decision

A month-2 capability: EU public procurement / TED (Tenders Electronic
Daily) lookup. Query active government contracts by keyword and return
structured results. The row states no clean agent-friendly API exists for
this today.

## Context

The row's stated basis, from the row's own Rationale: ChatGPT suggested
this pre-pivot. Sales agents finding government contract leads is judged
a real, recurring, monetizable B2B use case; TED scraping is painful, and
wrapping it in a single `strale.do()` call is judged high-value. The row
targets it as a month-2 build alongside a Nordic registry expansion
(Danish CVR, Norwegian Brønnøysund).

The historical Notion scope field on this row was `global` in the
workspace's old vocabulary. It is recorded here as `scope: product`: this
is a capability-roadmap item, not a single technical integration decision.

## Rationale

The rationale, as the row states it: government-contract leads are a real
recurring B2B need; TED itself is painful to query directly; wrapping it
in one API call is high-value, and the timing (month 2, alongside a
Nordic registry expansion) reflects the row's assessment of build
priority at the time.
