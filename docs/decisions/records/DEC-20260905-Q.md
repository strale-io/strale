## Decision

The quotation convention for this candidate set is unchanged from
`DEC-20260905-N`: normalize quotation and source before comparing:
transliterate `€` to `EUR`, `×` to `x`, `≥` to `>=`, `≤` to `<=`, `→` to
`->`, `…` to `...`; lowercase; delete every character that is not a
letter or digit. A quotation is faithful when its normalized form is a
substring of the normalized source (an ellipsis splits it into ordered
segments). Punctuation, dashes, quote marks, case, markdown emphasis,
whitespace and the punctuation at a truncation point are therefore never
defects. Defects are: a word inserted, dropped, replaced or reordered; a
composite presented as one quotation; a quotation whose named source does
not contain it (wrong file, function, document, record or row field); a
quotation attributed to a source outside the repository, the parsed row,
the sibling frontend checkout or a merged pull request; and any false
statement about repository state at the commit. `DEC-20260905-N` adds one
clause, unchanged here: a double-quoted span a record attributes to no
source, and that is not presented as the words of a row, file, page or
person, is the record's own wording, judged as prose, not as a quotation.

This record's main point is a second clause, stating the rule the corpus
has in fact been applying since `DEC-20260905-G`: a resolution report
under `archive/sessions/` is an immutable archive file; where it carries
a statement that an amending record has withdrawn from the formal record
for the same collision id, that withdrawal governs the statement
wherever it appears, the report is never edited, and the report is not a
separate defect. This clause does not excuse any false statement: the
statement stays withdrawn and the report stays flagged as carrying stale
text regardless of whether any record names the report by path. It
replaces an enumeration requirement that has now failed three times, so
a later round applies the rule uniformly instead of depending on whether
a given report was individually listed.

## Rationale

A span presented in parallel with a verbatim quotation reads as a
quotation and is judged as one. A rule the corpus applies in practice
should be written down once rather than re-enumerated per instance. An
enumeration that has missed a case in each of three consecutive rounds is
the wrong mechanism for a class this size.
