## Decision

Published Strale to the Official MCP Registry as `io.github.strale-io/strale`,
version `v0.1.1`.

## Context

The historical Notion scope field on this row was `global`. It is recorded
here as `scope: technical` under this repository's decision-record
vocabulary: this decision is a publication and rail mechanic (getting the
package onto the canonical MCP registry), not a positioning or product
choice.

## Rationale

The Official MCP Registry is the canonical MCP registry: other registries
and subregistries pull from this source, so publishing there propagates
Strale's listing outward. Published with both stdio (npm `strale-mcp`) and
remote (`https://api.strale.io/mcp`) transports. Required GitHub org
membership to be set to public for namespace authentication (the
`io.github.strale-io` namespace is authenticated against public membership
of the `strale-io` GitHub organization).

## Consequences

Status verified on 2026-09-04, against `main`.

**The published version has moved past v0.1.1, and the registry manifest and
the npm package manifest disagree on what the current version is.**
`server.json` at the repository root (root-required by the MCP registry
crawler; verified present) states `"version": "0.2.3"` for both the top-level
server entry and its `packages[0]` npm package entry (`strale-mcp`
`0.2.3`). `packages/mcp-server/package.json`, the actual npm package
manifest, states `"version": "0.2.8"` — five patch versions ahead of what
`server.json` declares. Both are newer than the `v0.1.1` this row recorded,
but `server.json` itself is stale relative to the npm package it describes.
`server.json` still declares both transports this row names: `packages[0]`
carries `"transport": {"type": "stdio"}` for the npm package, and a
top-level `remotes` entry carries `"type": "streamable-http", "url":
"https://api.strale.io/mcp"`.

**The npm-publishing procedure this row's publication predates now exists as
a written, repo-checked contract.** `docs/release/npm-publishing.md`
documents the post-publish production contract smoke test (CLAUDE.md's
Distribution PR Integrity Protocol, step 6) required after any publish of a
`*-strale` package, including `strale-mcp`.

**A later incident on this exact publication surface postdates this row and
bears on it directly.** CLAUDE.md records that on 2026-08-22 a production
contract smoke test found `strale-mcp` had shipped `0 cap trust, 0 sol
trust` for roughly 3.5 months: trust routes were deleted in May, the admin
wall on their prefix answered 401 instead of 404, and the client logged the
degradation to invisible stderr and carried on. That incident is closed
(`project_mcp_trust_incident_2026_08` in project memory; CLAUDE.md's
Distribution PR Integrity Protocol step 6 is the structural fix), but it
shows that publishing to the registry (what this row records) and the
published package continuing to work correctly against production are
separate concerns that were not both covered by the process in place on
2026-03-13.

## Reversal conditions

Reconsider this decision if the Official MCP Registry publication path is
abandoned, if the `io.github.strale-io` namespace is renamed or migrated to
a different authentication method, or if `server.json` and
`packages/mcp-server/package.json` diverge further without either being
corrected — that drift should be treated as a live risk to the registry
listing's accuracy, not evidence this decision is inactive. Represent a
change of this decision through a new decision rather than editing this
protected record in place.
