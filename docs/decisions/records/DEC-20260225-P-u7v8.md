## Decision

Backend language: TypeScript. The MCP SDK is TypeScript-native, this
gives ecosystem alignment, and it allows a seamless addition of an MCP
server layer later.

## Context

The row's stated basis, from the row's own Rationale: the MCP SDK is
TypeScript-native and most MCP developers work in the TypeScript
ecosystem, so adding an MCP server layer later is seamless in TypeScript;
AI coding tools work equally well for TypeScript and Python, so the
non-technical founder's experience is similar either way; a Python SDK
for client-side use is planned for week 3-4.

The historical Notion scope field on this row was `global` in the
workspace's old vocabulary. It is recorded here as `scope: technical`:
this is the backend language and runtime choice.

## Rationale

The rationale, as the row states it: TypeScript-native MCP tooling and
ecosystem alignment made adding an MCP server layer later seamless, while
AI-assisted coding made the choice of implementation language roughly
neutral for a non-technical founder; a Python SDK for clients was already
planned to follow in weeks 3-4, independent of the backend language
choice.

## Consequences

Status verified on 2026-09-04, against `main`.

**This decision held without contradiction.** CLAUDE.md's Tech Stack
states "Runtime: Node.js + TypeScript" and "Framework: Hono," and
CLAUDE.md's Project Structure block shows the entire `apps/api/` backend
as TypeScript. The MCP server this row anticipated exists, also in
TypeScript: `packages/mcp-server/package.json` is part of the monorepo's
TypeScript package set, matching the row's premise that TypeScript would
make an MCP server layer seamless to add.

**The row's stated Python SDK timeline (week 3-4) is broadly consistent
with the eventual sequencing recorded elsewhere.** CLAUDE.md's DEC-23
states "TypeScript SDK ships before Python SDK," and CLAUDE.md's Project
Structure block lists both `packages/sdk-typescript/` (npm published) and
`packages/sdk-python/` (PyPI published) as existing; this verification
did not re-derive the exact week each shipped, only that both SDKs exist
in the order this row and DEC-23 both specify.

## Reversal conditions

None recorded on the row (`Superseded By` and `Outcome` are both null in
the source). No file found in this verification proposes changing the
