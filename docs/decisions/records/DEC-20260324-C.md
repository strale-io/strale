## Decision

AgentCash is complementary, not competitive. Position Strale as the
quality provider inside the x402 ecosystem rather than competing with
AgentCash on payment rails.

## Context

The historical Notion scope field on this row was `global`. It is recorded
here as `scope: product` under this repository's decision-record
vocabulary: this decision is a competitive-positioning call about how
Strale relates to another x402-ecosystem actor.

## Rationale

AgentCash (agentcash.dev) is a payment layer for x402 agent APIs with 250+
endpoints, near-zero traction, and zero quality/trust infrastructure.
Strale's SQS fills the gap AgentCash cannot. Rather than competing on
payment rails, Strale should make its capabilities purchasable through
x402/AgentCash while keeping trust as the unique moat. The identified risk:
if AgentCash becomes the default agent wallet, Strale's prepaid wallet
becomes friction. The identified opportunity: Strale as a trusted provider
inside their ecosystem.

## Consequences

Status verified on 2026-09-04, against `main`.

**AgentCash has a live, verified anchor in the codebase — this positioning
was executed, not just stated.** `apps/api/src/routes/x402-gateway-v2.ts`
contains explicit compatibility handling for AgentCash's discovery decoder
(`@agentcash/discovery`), and a comment names the "x402scan/agentcash
discovery spec" for the `x-payment-info` annotations the gateway emits.
`handoff/_general/from-code/2026-09-01-x402-agentcash-discovery-contract.md`
(PR #461, merged as commit `b4e3904f2e982dcd9e7bad83f4da8c21eb3621e7`)
records that paid capability and solution operations now emit canonical
`protocols: [{ x402: {} }]`, allowing `@agentcash/discovery@1.7.5` to
preserve their exact price and x402 advisory; production verification
against the live `b4e3904f2e98` deployment confirmed AgentCash correctly
parsed a paid `GET /x402/v2/csv-clean` (fixed `0.021600 USD`, `protocols:
["x402"]`) and a paid `POST /x402/v2/solutions/kyb-essentials-se` (fixed
`1.620000 USD`, `protocols: ["x402"]`), with no payment or settlement
occurring on the unpaid discovery call. This is later work (2026-09-01)
than this row's decision date (2026-03-24), and it substantiates the
"purchasable through x402/AgentCash" half of this row's positioning
directly: not a claim with no live anchor, but a shipped and
production-verified discovery-compatibility contract.

**The risk this row identified — the prepaid wallet becoming friction if
AgentCash becomes the default agent wallet — has not been resolved either
way.** No repository document records AgentCash's adoption level or wallet
share; the wallet-versus-x402 split this row's risk concerns is the same
split named in CLAUDE.md's "x402 Payment Gateway (March 2026)" paragraph
(x402 requires no signup or API key; the wallet is a separate, first-party
path), and the AgentCash discovery-compatibility work treats x402 as
additive to the wallet, not a replacement for it.

## Reversal conditions

Reconsider this decision if AgentCash begins competing directly on quality
or trust signals, if AgentCash's adoption materially erodes demand for
Strale's prepaid wallet, or if the discovery-compatibility contract this
row's positioning enabled is deprecated or removed. Represent a change of
this decision through a new decision rather than editing this protected
record in place.
