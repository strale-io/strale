## Decision

Set a communication gate at March 24: Sprint 9A through 9E, a landing
page review, and a Blog Post #1 draft must all be complete before the
first external post goes out.

## Context

The row's stated basis, from its own Rationale: an independent ChatGPT
evaluation had found SQS/success_rate confusion and test taxonomy drift,
and these had to be fixed before any external audience could encounter
the same issues. The landing page is the destination for all X/blog
traffic and had to be reviewed first. Blog Post #1 had to be ready so
launch day would not be "just tweets into the void."

The historical Notion scope field on this row was `global`. It is
recorded here as `scope: product`: it is a go-to-market sequencing gate
tied to specific launch content and review steps, not a purely technical
decision, though it names company-wide launch timing.

## Rationale

The rationale, as the row states it: shipping external communication
before fixing known confusion (SQS/success_rate, test taxonomy) and
before the landing page and first blog post were ready would put a flawed
first impression in front of the first external audience, so the gate
holds the launch date to those three prerequisites.
