## Decision

Split the original Phase 4 plan (authority enforcement bundled with
manifest-completeness enforcement) into **4a**, shipped immediately: strip
DB-canonical fields from backfill payloads, stopping a silent overwrite the
row names concretely ("manifest `price_cents=10` overwriting admin-tuned
`price_cents=5` on `lei-lookup`," surfaced by Phase 3 Gate 2); and **4b**,
deferred: fail-closed manifest-completeness enforcement, which requires
prerequisite cleanup of "242+ slugs currently missing required manifest
fields" before it can be enabled without blocking backfill on most of the
catalog.

## Context

different prerequisites"; 4a needs no prerequisite cleanup and stops "the
active footgun immediately"; 4b needs the 242+-slug cleanup first, or

## Rationale

The rationale, as the row states it: shipping 4a's contained fix
immediately closes an active authority footgun at low risk, while 4b's
larger prerequisite cleanup deserves its own audit and regeneration
strategy rather than blocking the smaller, independently valuable fix.

## Consequences

Status verified on 2026-09-05, against `main`.

**4a's authority-enforcement mechanism is present in the codebase today,
in a stricter form than this row describes.** `apps/api/scripts/onboard.ts`
carries a `--force-override-authority` flag explicitly labeled "Cluster 2
Phase 4a" in its own comments, gated to interactive TTY sessions and
refused in `--batch` mode, plus authority-drift detection logic loading the
existing DB row before a backfill. This is the mechanism this row's 4a
describes, evolved into an interactive-only guard rather than the row's own
narrower "strip DB-canonical fields from backfill payloads" framing alone.

**4b's audit output is present in the repository as an archived report, not
as code.** `archive/sessions/audit-reports/2026-04-20-phase-4b-audit.md`
documents the manifest-completeness backfill plan this row's 4b describes
(242+ manifests needing fields backfilled from DB-canonical values); this
record did not verify whether the fail-closed enforcement 4b calls for has
since shipped, since that would require re-auditing manifest completeness
directly, out of scope for this pass.
