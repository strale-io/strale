## Decision

Implement DEC-20260515-A's US v1 architecture (Tier 1 direct, Tier 2
Cobalt) with concrete per-state assignments, empirically derived from Phase
3 of the 2026-05-15 v1 audit (direct HTTP probes against each state's
access pattern).

TIER 1 DIRECT (7 capabilities to build for v1):

1. `us-ny-company-data` — Socrata SODA on data.ny.gov. Highest priority —
   NY is the second-most-incorporated US state and the Socrata API is the
   cleanest free US path.
2. `us-co-company-data` — Socrata SODA on data.colorado.gov.
3. `us-fl-company-data` — Sunbiz SFTP bulk (daily events + quarterly
   snapshots); free SFTP credentials issued on request.
4. `us-ma-company-data` — Corporations Book + data files via mass.gov;
   annual cadence, disclosed as a capability limitation (same pattern as SI
   on data.gov.si CKAN's slow refresh).
5. `us-wa-company-data` — CCFS CSV export from Advanced Search.
6. `us-tx-company-data` — Texas Comptroller CPA API (franchise tax +
   entity verification + SOS file number); partial field set — covers
   entity-status and basic identity but not officers/agents/registered
   agents. Defer a Comptroller + Cobalt overlay to v1.1+ unless customer
   demand emerges.
7. `us-sam-entity` — SAM.gov Entity Management API v3 (federal); requires
   a free system-account API key with a 1-4 week registration lead time.

Estimated build effort: ~8-12 person-days for all seven. NY+CO share the
Socrata-SODA pattern (~1 day each), FL+WA share the bulk-ingest pattern
(~1.5 days each), MA is bespoke (~1 day), TX Comptroller is REST-API (~1
day), SAM.gov is REST-API after the key arrives (~1 day).

TIER 2 COBALT (8 states routed through generic Cobalt orchestration for
v1): DE, GA, IL, MN, NV, NJ, PA, WY.

v1 launch gate: Cobalt's catalog coverage of these 8 states must be
verified during Cobalt onboarding — specifically Delaware, the
most-incorporated US state. If Cobalt is missing DE or any other of the 8
states with KYB-grade field coverage, this decision needs revision and v1
US scope may need to drop the affected states.

Structural note: the "scrape-only" category is empty by construction under
DEC-20260428-A (the no-scrapers doctrine). Every state with HTML-form-only
public access falls into the Cobalt Tier 2 bucket — Cobalt is the
legal-scrape-equivalent for these states under its commercial license,
consistent with the Tier-2 vendor pattern already established for Openapi
and OpenRegister.

Build queue priority within Tier 1: `us-ny-company-data`,
`us-sam-entity` (once the key arrives), `us-co-company-data`,
`us-fl-company-data`, `us-wa-company-data`, `us-tx-company-data`,
`us-ma-company-data` (lowest priority, annual cadence).

Deferred to v1.1+: TX Comptroller + Cobalt overlay for full field coverage;
a direct NV SOS API inquiry (could move NV from Tier 2 to Tier 1); an MN
$30/week paid CSV evaluation; a GA paid-bulk evaluation ($500 one-time /
$5K/year GTA partnership); IL/PA/WY paid evaluations (contract-based or
per-record pricing, lower priority).

## Consequences

Status on 2026-09-04, verified against `main`.

**None of the seven Tier 1 direct-state capabilities were built.**
`manifests/` has no `us-ny-company-data`, `us-co-company-data`,
`us-fl-company-data`, `us-ma-company-data`, `us-wa-company-data`,
`us-tx-company-data`, or `us-sam-entity` manifest, and no matching
executor exists under `apps/api/src/capabilities/`. The build queue this
row set never ran.

**Tier 2 shipped as a single 50-state Cobalt capability, not the 8-state
split this row specified, and it is dormant.**
`manifests/us-company-data-cobalt.yaml` and
`apps/api/src/capabilities/us-company-data-cobalt.ts` cover all 50 states
through Cobalt Intelligence, not only the 8 states (DE, GA, IL, MN, NV, NJ,
PA, WY) this row routed to Tier 2. `docs/company/DECISION-QUEUE.md` DQ-30
confirms the capability is `visible = false`, `x402_enabled = false`,
unreachable by any route, and that Petter's 2026-09-03 answer keeps it
dormant rather than either activating or deactivating it. The v1 launch
gate this row set — verifying Cobalt's coverage of Delaware and the other
7 states — was never exercised in a shipped, reachable capability.

**The commit id this row cites, `34036a0`, does not resolve on `main`.**
`git cat-file -e 34036a0` fails. The audit doc it names is at
`archive/sessions/stranded-research-2026-05/us-topograph-state-scout-2026-05-15.md`,
moved from the cited `apps/api/docs/` path; cited above at its current
location.

**DEC-20260812-A retired the Counterparty Assurance framing this per-state
classification served.** See DEC-20260515-A's Consequences section for the
full text; the per-state routing plan this row set has not itself been
built, so there is nothing beyond the single dormant Cobalt capability for
the retirement to act on.

## Reversal conditions

Reconsider this decision if any of the seven Tier 1 direct-state
capabilities are built, if Cobalt is activated and its coverage of the 8
Tier 2 states is verified against this row's launch gate, or if a future
customer-discovery track re-adopts per-state US KYB routing as a priority.
Represent a change of this decision through a new decision rather than
editing this protected record in place.
