## Decision

Change the homepage hero headline to "One API call. Verified data your
agent can trust."

## Context

The row's stated basis, from its own Rationale: the previous headline
("Any data your agent needs") positioned Strale as a data delivery
service that any API aggregator could equally claim. The new headline
keeps the "One API call" opening but shifts the second line from a
generic promise to a trust differentiation, putting the word "trust"
above the fold and using "Verified" to reinforce the testing story. The
row states four alternatives were evaluated, including category-first
and problem-first approaches, and this option "tested best for clarity
+ differentiation balance."

The historical Notion scope field on this row was `global`. It is
recorded here as `scope: product`: it is a specific homepage copy
change, not a company-wide strategic or positioning decision on its
own. The row's own text does not name any other Decision ID, so no
relation edge is recorded here; a broader homepage positioning decision
exists as DEC-20260302-C (T10 batch 15) but this row does not cite it.

## Rationale

The rationale, as the row states it: "trust" needed to appear above the
fold for a trust product, and "verified" needed to tie the headline back
to the testing and quality story rather than a generic data-delivery
claim. Four alternatives were tested and this wording won on clarity and
differentiation.
