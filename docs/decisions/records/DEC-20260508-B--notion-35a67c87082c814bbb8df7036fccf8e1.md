## Decision

Lock the canonical local-development worktree structure: trunk always on
`main`; daily work in `strale-work` (detached HEAD); research/exploratory
work in `strale-research` (detached HEAD). `WORKTREES.md` at the repo root
is the operational doc.

## Context

The row's Rationale states: "Three concurrent CC sessions on 2026-05-07 produced the Kyckr branch-confusion incident (HEAD-pointer collision in shared worktree). End-state of 2026-05-08 consolidation session: strale-spike worktree removed, two canonical worktrees created at named paths, WORKTREES.md committed to main via PR #71 (merge commit 9625aca). Detached HEAD on both work worktrees is deliberate — makes branch creation explicit and prevents the implicit-HEAD-clobber failure mode that triggered the Kyckr course-correction."

## Rationale

Per the row, Petter's own end-state report confirmed every required
condition: "trunk @ 9625aca, strale-work detached @ 9625aca, strale-research detached @ 8af4455 (acceptable, will refresh on next use), trunk untracked files preserved (8), zero stashes, WORKTREES.md present at repo root, both deleted branches gone locally + remotely." The row also records deferred,
out-of-scope items: "22 .claude/worktrees/* orphans (separate cleanup prompt), other lingering local branches, cc-prompts skill worktree-isolation rule still owed from 2026-05-07 course-correction."

## Consequences

Status on 2026-09-05, verified in files: `WORKTREES.md` exists at the repo
root, per `CLAUDE.md`'s Report Filing Convention, which lists `WORKTREES.md`
among the exact files the root may contain. The operating model has since
grown a per-agent worktree layer beyond the two named in this row:
`CLAUDE.md`'s Shared-Checkout Rule requires: Any agent that edits files MUST
be launched with `isolation: "worktree"`.** and its Session contract
requires that "the trunk stays on `main` and clean" across the whole
work-in-worktrees convention. This
extends the two-worktree model this row locked (`strale-work` /
`strale-research`) to a per-track worktree convention (`strale-wt-<track>`)
without superseding the underlying principle: trunk stays on `main`, and
concurrent work happens in isolated worktrees, never by branch-switching the
shared checkout.

## Reversal conditions

Supersede this decision if the two-worktree naming convention is replaced
by a different structure at the founder's direction, or if `WORKTREES.md`
is removed from the repository root.
