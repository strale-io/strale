## Decision

Strale expanded to 13 capabilities across 5 categories: Nordic company
intelligence (SE/NO/DK/FI), EU compliance (VAT, TED procurement), document
processing (invoice, PDF, annual report), data extraction (web, company
enrichment), and utilities (IBAN, PII redaction). The EU AI Act audit
trail and API versioning are stated as deployed alongside this expansion.

## Context

The row's stated basis, from the row's own Rationale: build velocity
exceeded expectations, with 8 new capabilities built and deployed the same
day as the original 5. The Nordic registry trio (Norway, Denmark, Finland)
is described as sharing a pattern with the existing Swedish capability.
The globally useful additions (IBAN, PII redact, PDF extract, company
enrich, TED procurement) are framed as addressing a "thin catalog"
concern and positioning Strale as a platform rather than a
single-capability API.

The historical Notion scope field on this row was `global` in the
workspace's old vocabulary. It is recorded here as `scope: product`: this
is a capability-catalog milestone, not a single technical integration
decision.

## Rationale

The rationale, as the row states it: unexpectedly high build velocity
made same-day expansion from 5 to 13 capabilities possible; the specific
additions were chosen to broaden category coverage (Nordic registries,
document processing, utilities) rather than deepen any single vertical,
directly addressing a perceived thin-catalog risk.

## Consequences

Status verified on 2026-09-05, against `main`.

**The catalog has grown roughly 26x past this row's count, and every
category this row names still exists among today's capabilities.**
`ls manifests/*.yaml | wc -l` returns 342 manifests on `main` as of
2026-09-05 (this batch's session), a date-stamped count per this batch's
fidelity requirement, versus this row's 13. Nordic registries
(`swedish-company-data`, `norwegian-company-data`, `danish-company-data`,
`finnish-company-data`), EU compliance (`vat-validate`,
`ted-procurement`), document processing (`invoice-extract`,
`pdf-extract`, `annual-report-extract`), data extraction (`web-extract`,
`company-enrich`), and utilities (`iban-validate`, `pii-redact`) all exist
as manifests today, matching this row's five categories by name.

**Same day this row was decided, the catalog was expanded further to 35;
see `DEC-20260226-P-w7x8`.** This record does not repeat that
capability-count verification.

**"8 new capabilities built and deployed same day" is consistent with
the platform's later, much larger build-velocity claims.** The next day's
`DEC-20260227-P-a1b2` states "Actual build velocity produced 133+
capabilities in <24hrs (heading to 200+)," the same pattern of rapid
same-day capability growth this row describes at smaller scale. This
verification did not independently re-derive the exact per-day capability
counts from git history; it relies on the rows' own stated figures and
the present-day manifest count as the two fixed points.
