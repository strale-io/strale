## Decision

The quotation convention for this candidate set is unchanged from
`DEC-20260905-D`: normalize quotation and source before comparing:
transliterate `€` to `EUR`, `×` to `x`, `≥` to `>=`, `≤` to `<=`, `→` to
`->`, `…` to `...`; lowercase; delete every character that is not a
letter or digit. A quotation is faithful when its normalized form is a
substring of the normalized source (an ellipsis splits it into ordered
segments). Punctuation, dashes, quote marks, case, markdown emphasis,
whitespace and the punctuation at a truncation point are therefore never
defects. Defects are: a word inserted, dropped, replaced or reordered; a
composite presented as one quotation; a quotation whose named source does
not contain it (wrong file, function, document, record or row field); a
quotation attributed to a source outside the repository, the parsed row,
the sibling frontend checkout or a merged pull request; and any false
statement about repository state at the commit. The relation rule is also
unchanged: a relation declared in a record's frontmatter whose basis is
stated in an amending record, or narrated in the target record's own
body, is substantiated; the narration need not live in the source
record's own body once that basis is stated somewhere reachable from the
record (this is the same convention `DEC-20260905-B` used to excuse
`DEC-20260314-A`'s and `DEC-20260423-A`'s reciprocal-narration gaps).

The statements listed below are withdrawn from the named records and
replaced by the facts stated here. One item (6) is not a withdrawal: it

## Rationale

One amending record per remediation round keeps history immutable, keeps
the reviewer trail intact, keeps the validator's protections untouched,
and matches a stable evidence file
(`archive/sessions/2026-09-05-m2-closing-review-round-4.md`). The
quotation convention, restated unchanged from `DEC-20260905-D`, continues
to remove reviewer disagreement about what counts as a defect; it does
not weaken the bar on words, attribution, or facts. A checker residual is
a defect unless the source text that contains it is located and quoted;
this record's own reconciliation quotes the located source for every one
of the 94 checker misses it reports (or, for the 83 self-referential
parsing artifacts inside `DEC-20260905-C.md` and `DEC-20260905-D.md`,
demonstrates why the checker's quote-pairing algorithm produces a
non-quotation span from a document that is itself about quotations,
rather than merely asserting it).

A statement about whether a sibling record exists is a repository-state
claim like any other and is checked against the records directory at the
commit, never carried forward from an earlier batch. Four of this
record's six withdrawal items are exactly this class: a note that was
accurate on the day it was drafted became false the moment a later batch
created the record it denied existed, and nothing in the review process
before this round re-checked it. The fix is not to blame the original
authors — the note was true when written — but to check every such claim
against the commit under review, the same discipline already applied to
every quotation.

A relation substantiated by an amending record, or narrated in the
target record's own body rather than the source record's, is not a
lesser form of substantiation: the frontmatter `relations` array and the
body prose (in either the source or the target record) are both part of
the same corpus, and nothing in `scripts/decision-records-lib.mjs`'s
validator requires the substantiation to live in the source record's own
file, or even in the same file at all. `DEC-20260409-D`'s relation to
`DEC-20260409-A` is substantiated both ways here: from the two rows'
shared Source field and same-day decision, and from `DEC-20260409-A.md`'s
own already-merged prose naming `DEC-20260409-D` as the gate that later
filled its stated gap. Requiring an edit to `DEC-20260409-D`'s own body
to add the missing narration would violate the same active-record
immutability this record otherwise honors.
