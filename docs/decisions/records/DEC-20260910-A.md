## Decision

Directed by Petter in session on 2026-09-10 ("go with option 1, waive all
36"): all 36 pending rows of `docs/programs/codex-review-backlog.yaml`
(CX-1 through CX-36; 23 high priority, 13 medium) are closed `waived`,
`waived_by: petter`, citing this decision. No new batches are added to the
register. `npm run codex:check` remains in force so the waived history
cannot be edited, deleted, or reopened.

## Context

On 2026-09-07 the founder removed the mandatory cross-provider review
requirement (the founder review policy referenced by this decision's own
title): a required independent review may use the same provider in a
separate review context, a different provider is optional, and work is not
blocked solely because another provider is unavailable or has not reviewed
it. That policy change removed the obligation
`docs/programs/codex-review-backlog.yaml` existed to track. Every one of the
register's 36 rows had already passed `policy.review_by` of 2026-09-07,
which made `npm run codex:check` fail on `main` and blocked every pull
request in the repository from 2026-09-07 until this decision, on
2026-09-10 (the last merge before the block was on 2026-09-06).

## Rationale

The founder's own stated rationale, quoted from CLAUDE.md's Review routing
section: the 2026-09-07 policy change "removed the obligation
`docs/programs/codex-review-backlog.yaml` existed to track," so continuing
to block every PR on a register tracking a now-defunct obligation served no
purpose. Waiving the existing rows resolves the block without pretending the
underlying Codex re-reviews happened; the register and its checker remain so
the waived history cannot quietly be rewritten later.

## Consequences

The register and `npm run codex:check` stay in place; the checker's
immutability guarantees now apply to the waived rows exactly as they would
to a Codex-verdict closure. `docs/programs/codex-review-backlog.yaml`'s own
header documents the closure mechanism (a row closes by an archived Codex
verdict cited by path, or by a founder waiver naming its decision), and
this decision is the named waiver for all 36 rows. This decision amends
`DEC-20260903-A` (the register's founding decision) without deleting or
retiring that register; an independent same-provider review in a separate
context now satisfies the review requirement going forward, and a PR
states which review ran.

## Reversal conditions

Supersede or amend this decision only with a new founder decision that
reinstates a Codex-specific review obligation for the waived rows, or that
reopens the mandatory cross-provider review requirement the 2026-09-07
policy removed. `npm run codex:check`'s immutability guarantee means a
waived row's status, commit, or verdict cannot be edited going forward
regardless of a future policy change; a reversal would need a new decision
and, per the checker's own design, cannot rewrite this decision's already
recorded closures.
