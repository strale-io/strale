## Decision

The homepage leads with solutions and trust positioning, not
infrastructure/API messaging. Categories are removed from the homepage
(kept live on `/capabilities`). A vision statement is added. A solutions
showcase replaces the stats strip as the section that follows the hero.
Problem/solution framing is added.

## Context

The row's stated basis, from its own Rationale: developers need to see
outcomes before plumbing. The hero shows a "Verify a Swedish company"
solution using real Klarna data (org 5567370431).

CLAUDE.md's "Current Decisions (March 2026)" section lists this row by
its short form ("DEC-20260302-C: Homepage leads with solutions and trust
positioning") alongside its neighbours DEC-20260302-A/B, DEC-20260303-D/E,
DEC-20260303-G, DEC-20260305-A through G, DEC-20260306-A through F, and
DEC-20260307 (the SQS Constitution), the same launch-week cluster this
batch draws several other rows from.

The historical Notion scope field on this row was `global`. It is
recorded here as `scope: product`: it directs a specific homepage
composition and messaging choice, not a company-wide strategic or
technical decision.

## Rationale

The rationale, as the row states it: developers need to see outcomes
before plumbing. A solutions showcase using real data (the Klarna
example) demonstrates value directly, rather than leading with API
infrastructure messaging that reads as plumbing.
