## Decision

Move Sprint 9F (the zero-auth free tier via MCP) from Phase B "Launch
+3d" to "Launch day/+1d," elevating it to immediate priority.

## Context

The row's stated basis, from its own Rationale: "Auth wall is the #1
blocker for autonomous agent activity. 2027.dev AX research confirms
auth causes 40% of agent failures. Without zero-auth free tier, content
launch drives discovery but agents can't convert to usage." The row
states this moves Sprint 9F "from Phase B Launch +3d to Launch day/+1d."

The historical Notion scope field on this row was `global`. It is
recorded here as `scope: technical`: it is a sprint-sequencing decision
inside a build plan, not a company-wide strategic or positioning
decision.

## Rationale

The rationale, as the row states it: a zero-auth path has to exist by
the time discovery content starts driving traffic, or agents that find
Strale cannot convert into usage; shipping it three days after launch
was too late for that funnel to work.

## Consequences

Status verified on 2026-09-05, against `main`.

**A zero-auth path exists today for a defined slice of the catalog.**
`packages/mcp-server/README.md` states that `strale_ping`,
`strale_search`, `strale_methodology`, and `strale_trust_profile` work
without an API key, and that `strale_execute` is free-tier-capable
without one for free-tier capabilities specifically. CLAUDE.md's
free-tier paragraph independently confirms 11 capabilities require no
auth or signup, surfaced via `GET /v1/platform/facts`
(`free_tier_slugs`). This matches the row's own description of the
target ("free capabilities via MCP without auth"), though the row's own
text names five capabilities and CLAUDE.md's current count is 11; this
record does not attempt to reconcile the two counts, only that a
zero-auth capability set exists.

**"Sprint 9F" itself is not tracked in the repository.** No file under
`docs/strategy/` mentions "Sprint" (`grep -rln "Sprint" docs/strategy/*.md`
returns nothing), so this record cannot confirm whether the specific
sprint-numbering and phase-timing language ("Phase B Launch +3d,"
"Launch day/+1d") the row describes survives anywhere, only that the
underlying zero-auth capability the sprint was meant to deliver exists
in the shipped product today.

## Reversal conditions

None recorded on the row (`Superseded By` and `Outcome` are both null).
The zero-auth capability set (11 free-tier capabilities today, per
CLAUDE.md) is what shipped in place of the specific sprint-timing
language this row describes.
