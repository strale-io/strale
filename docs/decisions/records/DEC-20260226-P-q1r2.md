## Decision

Strale MVP live. The API is deployed to Railway
(`strale-production.up.railway.app`). The TypeScript SDK is published as
`straleio@0.1.0` on npm. Five capabilities are working, with async
execution for slow capabilities, trial credits, and the full wallet flow.
A fresh `npm install` reaches real data in under one second.

## Context

The row's stated basis, from the row's own Rationale: the MVP milestone
was achieved ahead of the four-week schedule the founder had set. The core
hypothesis the row states as now testable: a developer can
`npm install straleio`, obtain an API key, and call `strale.do()` to get
structured data back from a live API with real wallet deductions. The five
capabilities named: `vat-validate`, `swedish-company-data` (with fuzzy
input), `invoice-extract`, `web-extract`, `annual-report-extract`.

The historical Notion scope field on this row was `global` in the
workspace's old vocabulary. It is recorded here as `scope: technical`:
this is a deployment and package-publication milestone, not a strategic or
positioning decision.

## Rationale

The rationale, as the row states it: shipping the MVP ahead of schedule
validated the core hypothesis, that a developer can install the SDK and
receive real structured data through a paid wallet flow with no manual
setup beyond obtaining a key.
