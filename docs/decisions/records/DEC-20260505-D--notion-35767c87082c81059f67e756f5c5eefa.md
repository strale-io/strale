## Decision

Pursue the InfoCamere Distributore Ufficiale program (applied via
`richieste.distributori@infocamere.it`) as the redistribution path for
Registro Imprese data, rather than the Telemaco Pay retail channel.

## Context

The row's Rationale states: "The 2026-05-04 outreach to contatti@infocamere.it returned a generic redirect to the public assistance portal, confirming that mailbox is the wrong inbox for a B2B redistribution inquiry. Research today identified the correct path: the Distributore Ufficiale InfoCamere program, applied via richieste.distributori@infocamere.it. ~70 Italian companies hold this status (Cerved, EasyFintech, Visure Italia, TuttoVisure, etc.). This is the formal mechanism for embed-and-bill of Registro Imprese data to downstream customers via a Strale-fronted API."

## Rationale

Three eligibility risks were disclosed upfront in the application rather than
hidden, per the row's own text: "(1) pre-revenue financials vs InfoCamere's stated 'bilancio in attivo' requirement; (2) Swedish AB as functional but not literal equivalent of società di capitale; (3) Article 134 T.U.L.P.S. license is prefectorial-issued and Italian-only — open question whether non-Italian distributors have an alternative path or must form an Italian subsidiary. Disclosing upfront forces InfoCamere to either accept and document the path or decline cleanly, both of which are better outcomes than discovering the constraint mid-process." The row records a fallback if declined: "sub-license through an existing Distributore Ufficiale (worse economics, faster path)."

## Consequences

Status on 2026-09-05, verified in files: `manifests/italian-company-data.yaml`
declares `data_source: Openapi.com IT-Advanced (Tier-3 vendor aggregator;
Italian company-data product line)`. Italy did not launch on the InfoCamere
Distributore Ufficiale path this row pursued; it launched on the Tier-3
Openapi.com aggregator path that
`DEC-20260507-C--notion-35967c87082c817cad56ec58c707d895` records as the
IT/ES/PT/AT cohort default, with direct InfoCamere integration deferred as a
v1.1 quality upgrade. `apps/api/src/capabilities/auto-register.ts` states "Final EU30 country to reach code parity — Phase 2c completes 30/30." and, on later lines, "InfoCamere integration per DEC-20260507-C." as the deferred direct-registry item. This row's own InfoCamere application
outcome is not recorded in the source data (the `Outcome` field is null); no
file in this repository documents whether InfoCamere accepted, declined, or
never responded to the Distributore Ufficiale application.

## Reversal conditions

Supersede this decision if Strale abandons the InfoCamere redistribution
path entirely (for example, if the Openapi.com Tier-3 aggregator relationship
becomes the permanent IT sourcing strategy rather than an interim one) or if
InfoCamere's program terms change in a way that forecloses the eligibility
path this row describes.
