## Decision

Build the website redesign inside this repository, as `apps/web`, in the
monorepo. Preserve first, then build: `strale-frontend` is swept and its
design material preserved (release `preserve-2026-09-02`, archive tags,
tracked candidates) and is kept, not extended, until `apps/web` serves
production. Design-token work lands in `apps/web`.

## Context

Directed by Petter 2026-09-02. This decision has no dedicated repo-native
strategy document beyond CLAUDE.md's own entry and the program register it
points to; CLAUDE.md's own text is the primary source, with a Notion
Decisions DB entry filed 2026-09-02 as the original record of the founder
session.

## Rationale

CLAUDE.md's own stated rationale is minimal beyond the decision itself and
its named reversal condition. The preserve-then-build sequencing avoids
losing `strale-frontend`'s design material and existing production
behaviour while a new monorepo-hosted implementation is built, rather than
extending or replacing the existing frontend in place.

## Consequences

Status verified 2026-09-11, against this branch: no `apps/web` directory

`DEC-20260902-A`."
