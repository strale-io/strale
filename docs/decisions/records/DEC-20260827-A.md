## Decision

`austrian-company-data` migrates to the official Firmenbuch via the
JustizOnline IWG/HVD API. This supersedes the Openapi.com WW-Top path for AT;
the Openapi relationship for the other nine countries it serves is unaffected.
The migration gains FN- and name-based input (WW-Top was VAT-only), legal
form, court, EUID, current officers with representation authority,
insolvency/dissolution legal facts, and €0 external cost. Provenance:
acquisition method `direct_api`, with CC BY 4.0 attribution carried in every
response.

## Context

JustizOnline/BRZ issued Moonlighter AB an IWG reuse token for the Firmenbuch
HVD API on 2026-08-27 (application filed 2026-08-13; terms CC BY 4.0,
attribution required per response). This is the exact reactivation trigger
named in the historical `DEC-20260427-I-6` record ("licensed contract with the
Austrian Justizministerium for direct Firmenbuch API access") and sits at the
top of the `DEC-20260813-A` preference order: official API > licensed bulk >
Tier-2 vendor > per-call parsing. The Openapi.com WW-Top path being superseded
was a Tier-3 aggregator that was never activated for AT — it was gated on the
case-151296 countersignature.

## Rationale

A vendor-switch checklist was run: the drift sweep found zero AT findings, and
there is no per-AT `STATIC_FACTS` vendor entry, consistent with the existing
SE/SK direct-registry precedent. The official API outranks every alternative
in the `DEC-20260813-A` preference order, and it is strictly richer than the
WW-Top path (name-search plus officer and legal-fact coverage that VAT-only
lookup never had), at zero external cost. Confirmed by Petter in chat on
2026-08-28 after the decision draft shipped in PR #410's description.

## Consequences

Shipped and activated 2026-08-27: PR #410 (migration, 8-angle review), PR #414
(manifest corrections), and activation via `DQ-20` under Petter's explicit
approval. Live at €0.05 with x402 enabled; prod test suite passed 7/7 at
activation. This record cites `DEC-20260427-I-6` and `DEC-20260813-A` in prose
only. `DEC-20260427-I-6` has no row anywhere in the M2 closure register or the

## Reversal conditions

Supersede this decision if the JustizOnline IWG token is revoked, the
Firmenbuch HVD API's terms change in a way that breaks the CC BY 4.0
attribution basis, or a founder-approved decision reactivates the Openapi.com
WW-Top path for Austria.
