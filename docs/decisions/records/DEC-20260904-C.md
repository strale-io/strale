## Decision

Capabilities labelled Unverified are listed on the website with the label,
not hidden. strale.dev lists such capabilities dimmed with an "Awaiting
traffic" badge. Pending and Building-track-record states keep their
existing behaviour. This affirms `DEC-20260313-C` and the current
behaviour.

## Context

Directed by Petter on 2026-09-04 on an M2 batch-9 finding whose premise
turned out stale: the website's `isSQSUnqualified` filter would have hidden
every capability labelled Unverified, but the finding's investigation
showed the function has had no callers since the 2026-08 audit follow-up,
and strale.dev already lists such capabilities dimmed with the "Awaiting
traffic" badge rather than hiding them. The dead filter was aligned with
the decision in `strale-frontend` PR #24 (kept in maintenance under
`DEC-20260902-A`) so a revived caller cannot reintroduce hiding.

## Rationale

CLAUDE.md's stated lesson from this finding: "a comment is not evidence of
behaviour; check the callers." The finding investigated whether a filter
function's existence implied it was in effect; it was not, because nothing
called it. The decision affirms the current, verified behaviour rather than
treating the dead function's mere presence as license to activate hiding.

## Consequences

`strale-io/strale-frontend`'s `sqs-display.ts` still exports
`isSQSUnqualified` as a dead function (verified against this branch's
sibling checkout, 2026-09-11): the function exists but this record does not
independently re-verify it has zero callers beyond CLAUDE.md's own claim.
Notion Decisions DB entry filed 2026-09-04; this record is the repo-native
continuation through the M2 closure path CLAUDE.md names.

## Reversal conditions

Supersede this decision only with a new founder decision to hide Unverified
capabilities, or to change the Pending or Building-track-record display
states. Removing the dead `isSQSUnqualified` function entirely, or adding a
caller that respects this decision's "list, don't hide" rule, does not
require supersession.
