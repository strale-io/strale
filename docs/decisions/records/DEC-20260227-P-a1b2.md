## Decision

Provider Growth timeline accelerated: Phase 0 is 200+ capabilities at
launch, not the originally planned 5 seed capabilities.

## Context

The row's title carries the whole decision; its Rationale supplies the
substance. The original Provider Growth document assumed 5 seed
capabilities and a 3-month sole-provider phase. The row states actual
build velocity produced 133+ capabilities in under 24 hours, heading
toward 200+, making Phase 0 launch-ready with a full catalog rather than
a minimal seed set. The row also states the provider-recruitment timeline
shifts from month 3 to month 2 as a consequence.

The historical Notion scope field on this row was `global` in the
workspace's old vocabulary. It is recorded here as `scope: product`: this
is a roadmap-timeline revision, not a single technical integration
decision.

The "5 seed capabilities" this row names as the original Provider Growth
plan's assumption is the same number as, but not explicitly identified
with, the `DEC-20260225-P-w9x0` MVP seed-capability list; this row's own
text names only "the original Provider Growth doc," not `w9x0` or the
capability-count milestones `DEC-20260226-P-u5v6` (13) and
`DEC-20260226-P-w7x8` (35) record, so no relation edge is recorded to any
of them per this batch's source-stated-only rule.

## Rationale

The rationale, as the row states it: the original 5-seed-capability,
3-month-sole-provider plan was overtaken by actual build velocity (133+
capabilities in under 24 hours); Phase 0 is redefined as full-catalog
launch-ready, and provider recruitment is pulled forward from month 3 to
month 2 accordingly.

## Consequences

Status verified on 2026-09-05, against `main`.

**The capability count target was reached and then vastly exceeded: 342
manifests exist on `main` today** (`ls manifests/*.yaml | wc -l`, dated
2026-09-05, this batch's session), well past this row's 200+ figure.

**The accelerated provider-recruitment timeline this row anticipates was
never realized: no third-party provider has ever been onboarded.**
`DEC-20260225-P-g9h0`'s Consequences (filed against the row proposing the
provider-lite contractor model this row's accelerated timeline feeds
into) found no evidence of any third-party provider, contractor or
otherwise, having ever been onboarded, citing an unchanged CLAUDE.md DEC-4
("Founder is the only provider for first 3 months") and no "provider"
match in `docs/company/WORKFORCE.md` or the readiness program document.
This record does not repeat that verification; the same finding applies
directly to this row's own "provider recruitment timeline shifts...to
month 2" clause, which never executed as a recruitment event of any kind.

**The following day's `DEC-20260227-P-o5p6` restates and extends this
row's Phase 0 figure into a full four-phase sequence**; see that record
for the fuller sequencing picture this row's acceleration fed into.

## Reversal conditions

None recorded on the row (`Superseded By` and `Outcome` are both null in
the source). The capability-count target itself was reached and
exceeded; the provider-recruitment timeline it anticipated was not
executed and no later record was found formally abandoning it, so this
row stands as a decision whose capability-scope half succeeded and whose
provider-timeline half did not occur.
