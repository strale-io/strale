## Decision

Trust display system rules: one chart (`TrustBarChart`), one calculation
(`calculatePassRate`), one severity vocabulary
(healthy/minor_issue/degraded/unhealthy), one narrative tone. Four rules
enforced across 9 files.

## Context

Trust data was rendered independently in each component, leading to
inconsistencies: a sparkline in one place and a bar chart in another,
different pass-rate calculations, different color thresholds, a
"Degraded" label appearing in narrative text where it should not. The
historical Notion scope field on this row was `global`. It is recorded
here as `scope: product` under this repository's decision-record
vocabulary: this decision governs how trust data is presented to
customers across the product's surfaces, not an internal engineering
convention.

## Rationale

Four rules were established and enforced across 9 files: the sparkline
component was deleted; `calculatePassRate()` replaces 8 inline pass-rate
calculations that had drifted from each other; a `QualitySeverity` type
plus `SEVERITY_LABELS` centralizes the severity vocabulary
(healthy/minor_issue/degraded/unhealthy); the backend narrative generator
uses descriptive phrases rather than severity labels directly, so the
narrative tone cannot silently diverge from the severity vocabulary.
Outcome recorded: shipped. `TrustBarChart` extracted as a standalone
component; the sparkline was removed from the codebase; `calculatePassRate`
used everywhere; the severity vocabulary defined; the narrative generator
updated to 5-tier descriptive phrases.

## Consequences

Status verified on 2026-09-04, against `main`.

**The subject this row displays — the SQS engine — was deleted.** The
Strale Quality Score engine (the dual-profile QP/RP model, the 5x5 matrix,
`min_sqs`, the public `/v1/quality/:slug` endpoint, the trend and guidance
columns, and the automatic lifecycle transitions) was deleted per
DEC-20260503-B (PR1 shipped 2026-05-05; CLAUDE.md: "SQS scoring engine
deleted per DEC-20260503-B"). This row's four display rules governed how
that engine's output was rendered; the engine they rendered no longer
computes anything live.

**A narrower trust surface survives under a new name and a narrower
contract.** `apps/api/src/routes/public-trust.ts` (`/v1/public/ops/trust/*`)
exists on `main` today. Its own header comment states why: the published
`strale-mcp` package called a now-deleted `/v1/internal/trust/*` path and
silently reported "0 cap trust, 0 sol trust" for roughly 3.5 months (the
admin wall on `/v1/internal/*` returned 401, not 404, for a path that no
longer existed). The replacement route deliberately narrows the surface:
`PUBLIC_TRUST_FIELDS` is `badge`, `badge_label`, `tested`, `last_tested_at`,
`pass_rate` — a boolean-plus-pass-rate badge, not a severity vocabulary or
a chart. The route's own comment states: "The retired SQS grades, guidance
strategy, and raw sub-scores are deliberately NOT projected: they were
retired, and reviving them here would recreate a scoring surface the
platform decided to stop publishing."

**`TrustBarChart` and `calculatePassRate` are not present in this
repository under those names.** A repository-wide search for
`TrustBarChart` and `calculatePassRate` across `apps/api/src` finds no
matches; both were frontend component/helper names. Per DEC-20260902-A the
website redesign lands inside this repository as `apps/web`, but that
directory does not exist on `main` as of 2026-09-04 (`ls apps/` lists only
`api`); the sibling `strale-frontend` repository, where the original
components lived, is out of scope for this record and named only in prose.
No frontend surface in this repository currently defines those exact
symbols.

**`apps/api/src/lib/trust-grade.ts` still exists and computes a freshness
grade and latency grade, used narrowly.** Its `computeFreshnessGrade`
export is imported and called in `apps/api/src/routes/do.ts`; its combined
`computeTrustGrade` function (a worst-of severity roll-up related in spirit
to this row's severity vocabulary) has zero callers anywhere in
`apps/api/src` outside its own file, confirmed by a repository-wide grep
for `computeTrustGrade` — dead code, not a live display path.

**The wire-shape rule for trust endpoints postdates this row.** CLAUDE.md's
"Wire-shape rule for `/v1/public/ops/trust/*` endpoints" (money as integer
cents, scores as 0-100 integers or 0-1 decimals, dates as ISO 8601, no
pre-formatted display strings) was adopted after a 2026-04-30 cert-audit
finding, roughly two months after this row. It supersedes this row as the
operative display-shape constraint for whatever trust surface exists today.

## Reversal conditions

Reconsider this decision if a future trust-display redesign reintroduces a
severity vocabulary or a combined chart surface; that redesign should cite
the live `/v1/public/ops/trust/*` contract and the wire-shape rule rather
than reviving this row's specific component names. Represent such a change
through a new decision rather than editing this protected record in place.
