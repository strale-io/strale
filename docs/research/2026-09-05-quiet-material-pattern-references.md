# Pattern references for the retained kit

The founder accepted the navigation/buttons/cards companion and authorised forms, icons and composition, followed by website/social/email application studies. This is reference evidence, not a new brand decision.

## Reference lock

Quiet Material and the founder's opening screenshot remain the primary visual target: Instrument Sans, the retained flowing-S mark, broad folded light, dark Dusk fields, solid reading surfaces, generous hierarchy and restrained pill actions. No external palette, font, radius or illustration style replaces those choices. Existing atmosphere files remain decorative assets with their existing rights limitations.

Three style searches covered restrained editorial forms, developer-product evidence and Attio. Full Refero style records inspected: Attio `9f0c028b-6b11-415e-ab92-f32e4597cbe2`, shadcn `c14c0a94-1037-449e-bf5b-4cb972656ac7`, OpenAI Developers `44317718-1e56-45e0-8de3-7ede70f34349`. These are interpreted reference records, not direct live-site audits. Two full screen records examined the Relume verification error and Around email error listed above. No customer data from reference screens is reproduced.

| Choice | Evidence | Bounded use |
|---|---|---|
| Fields sit directly on a plain reading surface | shadcn form separation; retained card guidance | Flat fields, explicit labels; no gradient within an input |
| Separate editorial pacing from task density | Attio storytelling/UI distinction | Larger marketing type and shorter copy; retain Strale sans, not Attio's serif |
| Functional icons carry the text colour | OpenAI Developers reference and bundled Refero icons guide | One original outline family for utility, not repeated decorative benefit icons |
| Put a repair next to an error | Relume and Around screens; W3C notifications | Keep values and explain correction; reject disabled-until-valid and premature error examples |
| Keep names visible above fields | W3C labels guidance | Placeholder never replaces a label; optional fields are explicit |
| Give form boundaries enough contrast | W3C non-text contrast | Stronger semantic field border; retain subtle hairlines for decoration only |
| Vary composition rather than card colours | Founder feedback and program section briefs | Split opening, open editorial middle, dark closing invitation |

## Implementation judgement

The form is a local preferences specimen, not a proposed Strale account or persistence product. Native selects, radios and checkboxes keep their familiar keyboard model. Errors appear after submission and clear as corrected. A separate local failure simulation tests recovery without calling a service. The small utility icon family uses original geometry with shared grid/stroke data; branded product illustration remains a different role.

Density budgets are starting authoring constraints, not scientific comprehension thresholds: one focal message per section, one primary action per group, no nested reading panel inside another reading panel, and a link to deeper information when the budget is exceeded. Exception records must explain the user need and include a reviewed narrow layout. Never truncate essential errors, legal text or accessibility labels to meet a word count.

The three application studies use one illustrative document extraction story under LAUNCH-PROOF.md. They do not establish live availability, pricing, source completeness, testing guarantees or customer-visible audit retrieval. Email is browser-reviewed composition only; real email clients and publication remain unqualified.
