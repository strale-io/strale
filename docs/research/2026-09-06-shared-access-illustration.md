# Shared-access illustration reference lock

The founder authorised the illustration recommended in the homepage brief. This is a bounded asset within the accepted Quiet Material direction. It is not a new homepage design, identity decision or public execution claim.

Refero search: “developer tools simple connection diagram editorial monochrome.” Full interpreted style records reviewed: shadcn `c14c0a94-1037-449e-bf5b-4cb972656ac7` and SST `7b6c53c7-7145-476e-aed8-f2367eef3adb`. These records are design interpretations, not audits of the current live sites. The earlier multi-reference pattern study remains the broader context. No external artwork, code, palette or typography is imported.

| Decision | Basis | Adaptation and boundary |
|---|---|---|
| Open, unframed composition | Founder’s card-density feedback and homepage brief | Five named nodes; connectors do the explanatory work. No large outer card or inner reading card. |
| Retained logo is the focal point | Accepted foundations and founder’s explicit logo retention | Reuse the existing lockup geometry. Its unresolved creation record remains unresolved. |
| Restrained functional geometry | shadcn’s monochrome, functional visual language | Use Strale’s existing ink, secondary ink and inverse roles. Do not borrow Geist, its radii, or its component grid. |
| Explanation separate from atmosphere | SST’s distinction between explanatory technical imagery and decoration | The diagram carries one relationship. No photograph, gradient, code window or status signal is needed within it. |
| Same topology, different narrow composition | Brief and accepted density rules | Wide: agent, Strale, three branches. Narrow: agent above Strale, then one trunk with three branches. Labels stay legible; no carousel. |
| Original editable vector | The relationship is geometric and labelled | Keep SVG masters and source geometry; embed the exact bundled font for portable exports. No image generation is needed. |
| Static relationship | Product proof boundaries | No travelling dots, arrows implying ordered execution, timers, completion states or actual tool outputs. |

The diagram means that an agent can use Strale to access tools for research, extraction and validation. It does not mean one request runs all three, all tools share an input schema, every route exposes the same record, or Strale performs the agent’s reasoning. Light and inverse variants adapt to the declared plain canvas roles; arbitrary placement over atmospheric images is outside their verified scope.

Verification should inspect actual rendered light/inverse masters and their responsive presentation, including minimum-width labels, connector visibility, logo clear space, equivalent text, font availability, overflow and static reduced-motion behaviour. A local preview cannot certify an implemented website or clear asset rights.
