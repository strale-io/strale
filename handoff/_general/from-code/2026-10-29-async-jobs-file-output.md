Intent: portfolio plan item 2.11 (DEC-20261024-B) — async jobs with file output, the platform piece audio transcription (2.3) and bulk OCR (2.4) need.

Built on the existing DEC-22 async path rather than beside it: the job record is still the `transactions` row, the poll is still `GET /v1/transactions/:id`, and money still moves reserve → execute → capture (released on failure).

- **Files.** An executor may return `files: [{ name, content_type, data }]`. Caps: 10 MB per file, 25 MB and 10 files per job (`lib/jobs/files.ts`). Over the caps is an execution failure, so nothing is charged. Bytes go in the new `job_files` table (Postgres; no object store, no new vendor) inside the same transaction as the completed status and the capture. The manifest (name, type, size, sha256) is written to `provenance.output_files`, which is inside the integrity-hash payload.
- **Serving.** The poll response gains `files[]`, each with a URL signed by a key derived from `AUDIT_HMAC_SECRET` (`deriveSubkey`) that expires an hour after the read. `GET /v1/files/:id?expires=&sig=` needs no API key; 403 bad signature, 410 expired, 404 once redacted/deleted/past 90 days.
- **Callbacks.** `callback_url` on POST /v1/do (https, public host, validated before money moves). Stored in `job_callbacks` in the setup transaction, so the reconciler's crash path calls back too. Signed `Strale-Signature: t=..,v1=HMAC(secret, t.body)`, secret from `GET /v1/jobs/webhook-secret` (primary key), `Strale-Event-Id` = transaction id. Up to 6 attempts (30s, 2m, 10m, 1h, 6h), 10 s each, no redirects, SSRF-checked per attempt via safeFetch. Payload carries no output.
- **Retention (DEC-20260504-B).** `jobs/async-jobs.ts`, 60 s tick: claims ≤25 due callbacks (SKIP LOCKED) and deletes files whose transaction is redacted/deleted or older than PII_RETENTION_DAYS (not on legal hold), plus settled callback rows on the same rule. 50 rows per batch, ≤10 batches per tick, each under advisory lock 20261029. Both tables are new, so the first run has no backlog.
- **Migration.** Block 0134 (ledger M077), every_boot, two new empty tables.
- **Tests.** `routes/async-jobs.integration.test.ts` (7, real Postgres) and `lib/jobs/jobs.test.ts`. The test capability is registered in-process and exists only in the lane database. Mutations checked: dropping the file insert fails 3 tests; removing the per-tick cap fails the bound test.
- **Not done / next.** Sync-path capabilities that return `files` drop them (only async stores files); 2.3/2.4 must declare avg_latency_ms > 10 s. No production capability returns files yet, so in production the feature is live but dormant until 2.3/2.4 land. Rotating AUDIT_HMAC_SECRET rotates webhook secrets.
