How Strale works

One request. Strale handles the rest.

Ask for the outcome.

Your agent sends one request—by task or capability—through the same Strale connection.

  • One request
  • Task or capability
  • Inputs and budget

The right capability, automatically.

Strale matches the request to one verified capability or a bundled workflow.

  • One connection
  • Capability matching
  • Clear price before execution

Strale handles the providers.

Strale executes the selected capability—or coordinates several—while the integrations stay behind the access layer.

  • Provider access
  • Validation and retries
  • Single or multi-step

A result your agent can use.

Integration

One connection. Built for your stack.

Use Strale through an SDK, direct API, MCP server or the agent framework you already use.

Start with the language you use.

Install the Strale SDK, ask for an outcome and receive a structured result.

npm install straleio
example.ts
Ready 
import { Strale } from "straleio";

const strale = new Strale({
  apiKey: "sk_live_..."
});

const result = await strale.do({
  capability_slug: "google-search",
  inputs: { query: "Stripe payment processing" },
  max_price_cents: 10
});

console.log(result.output);
Structured response
{
  "status": "completed",
  "capability_used": "google-search",
  "output": { "results": 7 }
}
from straleio import Strale, DoRequest

strale = Strale(api_key="sk_live_...")

result = strale.do(DoRequest(
  capability_slug="google-search",
  inputs={
    "query": "Stripe payment processing"
  },
  max_price_cents=10,
))

print(result.output)
